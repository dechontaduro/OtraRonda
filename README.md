# OtraRonda
App para calcular la ingesta segura de bebídas alcohólicas

## Pasos
- Selecciona el nivel máximo de alcohol en la sangre (BAC)
- Elige la bebida (% alcohol)

## Resultado
La app te dice en cuanto tiempo alcanzas ese nivel (Tiempo a objetivo) y después de alcanzado cada cuanto debes tomar un trago para permanecer en ese nivel (Ritmo Mantenimiento).
